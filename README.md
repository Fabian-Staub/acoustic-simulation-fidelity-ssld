# Acoustic Simulation Fidelity for SSLD

This repository contains the digital appendix to the Master's thesis

**Impact of Acoustic Simulation Fidelity on Deep Learning-Based Sound Localization**  
by **Fabian Staub**.

## Repository Structure

### `src/`

The `src` folder contains the main scripts used for the final experiments in the thesis. This includes the code used for data generation, model training, and evaluation.

### `backup/`

The `backup` folder contains additional scripts that were created or used at different stages of the project.

These files are kept for completeness, but they are not necessarily well organized or documented. Some of them are older versions, test scripts, or intermediate implementations that were useful during development but are not part of the final workflow.

## Note

This repository is still being cleaned up and may not be fully complete yet.
